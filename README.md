# AutoService Manager

Учебная информационная система автосервиса для студента Мажида Шахбанова, группа 3ИСП4. Проект написан на Python и SQLite. Система учитывает клиентов, автомобили, перечень услуг и заказ-наряды. Тема и модель данных отличаются от проекта студенческой библиотеки.

## Быстрый запуск

Нужен Python 3.10 или новее. Сторонние библиотеки не требуются для самой программы.

```bash
python seed.py
python app.py
```

`seed.py` создаёт `autoservice.db` и заполняет её тремя клиентами, тремя автомобилями, четырьмя услугами и тремя заказами. Повторный запуск не дублирует данные.

## Тесты

```bash
python -m unittest discover -s tests -p 'test_*unittest.py' -v
python -m pip install -r requirements.txt
python -m pytest tests -q --cov=database --cov=validators --cov=reports --cov-report=term-missing
```

## Файлы

- `database.py`: схема БД, CRUD, заказы, JOIN, статистика и поиск.
- `validators.py`: проверки года, телефона, цены, количества, статуса.
- `app.py`: консольное меню на 23 операции.
- `seed.py`: демонстрационные данные.
- `reports.py`: CSV, TXT, резервная копия SQLite.
- `schema.dbml`: ER-модель для dbdiagram.io.
- `docs/er_diagram.png`: схема связей таблиц.
- `tests/`: unittest и pytest.
- `docs/PROJECT_PLAN.md`: соответствие десяти лабораторным и действия для GitHub.

## Примечания

База SQLite содержит пять связанных таблиц. Связь между заказами и услугами реализована через `order_services` с сохранением стоимости на момент добавления услуги. Связи и ограничения обеспечивают целостность данных. Не храните реальные персональные данные клиентов в публичном учебном репозитории.

## Возможности программы
- Учёт клиентов и автомобилей.
- Оформление заказ-нарядов.
- Расчёт стоимости ремонта.
- Формирование отчётов.
